# v0.25-menu 参数菜单适配

本版基于 Git 标签 `v0.25`，保留其回血、原生维修、武器／大盾／轮胎保护，以及修满后的腿部火焰和跛行动画恢复。

用 mod 管理器导入 `ShieldVehicleResupply_v0.25-menu.zip`，替换原有 Shield Vehicle Resupply 安装。需要 Bingus Shared Loader v17+；v18 的 addon 自动发现声明已保留。另行安装提供 **ModOptionsMenu API 1 / version 2** 的参数菜单模组，打开 **Esc → MODS → 护盾载具回血补弹**。加载器和参数菜单是两个模组；Mod Bindings Menu 是用于自定义按键的另一种菜单。

第一行 **Language** 提供“简体汉字”和“English”，默认中文。应用后关闭并重新打开 Esc 菜单，更新本模组的标题、标签和说明；English 在提供者的原生样式中显示为 ENGLISH。语言只影响本模组。

菜单共 27 项：语言、总开关、回血方式、护盾半径与时限、三类载具回血速度、受伤冷却、补弹与速度、部位再生、原生维修、机甲腿部恢复、武器／大盾／轮胎保护、轮胎维修与间隔、网络车体回血、车体部位回填、本机权威限制、旧版部位回填、补给与实体刷新间隔、测试和附近实体诊断。

| 数值选项 | 菜单范围 | 步长 | 原默认值 |
|---|---|---|---|
| 护盾半径 | 1–100 米 | 0.5 米 | 14.5 米 |
| 护盾持续时间 | 0–300 秒，0 不限时 | 1 秒 | 45 秒 |
| 机甲／坦克／FRV 每秒回血 | 0–100% | 0.1% | 4%／3%／5% |
| 每秒补弹 | 0–100% | 0.1% | 10% |
| 受伤冷却 | 0–60 秒 | 0.5 秒 | 2 秒 |
| 轮胎维修间隔 | 0.5–30 秒 | 0.5 秒 | 2 秒 |
| 补给检查间隔 | 0.1–5 秒 | 0.1 秒 | 0.5 秒 |
| 实体刷新间隔 | 0.5–30 秒 | 0.5 秒 | 3 秒 |

回血方式是“游戏原生 / 旧版数值回填 / 关闭回血”，对应原来的 `heal=native|write|off`。比例在菜单显示为百分比，设置文件仍保存原字段和比例，例如 4% 保存为 `exo_heal=0.04`。

点击“应用”后，只将变更的字段保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\shield_resupply_settings.txt`，并通过原有恢复流程重新应用。语言变化不触发业务恢复。修改其他选项时会先关闭现有原生再生配置、归还暂存弹药和恢复轮胎参数，再让原有循环按新配置继续；写回失败仍使用原来的重试逻辑。关闭总开关执行同样的恢复流程。

旧配置没有 language 时默认中文，其他参数保留。`part=`、`shield=`、`weapon=`、`ammo_max=`、注释与未知字段不会在保存菜单选项时被删除；这些项目继续在设置文件中编辑。`native_zone`、`native_segments`、`native_force` 仍是文件高级配置。

菜单范围只限制菜单操作，不限制原有文件配置。如果文件数值超出菜单范围或不在步长上，菜单显示最接近的可选值，实际配置和文件保持原值，直到用户应用该行的新选择。注册和文件 `reload` 后，以有效配置覆盖菜单旧缓存；同步不会清掉尚未应用的编辑。手改设置仍需发送原有 `reload` 命令。

没装参数菜单、接口版本不支持或注册失败时，设置文件与命令继续可用，失败写入日志。菜单可晚于本模组加载；成功绑定后每个控件仅有一个回调。

## 离线验证

运行 `python tools/build.py`，然后 `python tests/mods_menu_test.py`。测试使用本地真实菜单源码的注册／应用／保存 API，在其游戏 UI hook 安装前停止，覆盖旧配置、加载顺序、缓存优先级、未应用编辑、中英来回切换、比例映射、设置保留、重启、外部 reload、错误值、保存失败、缺失或故障的菜单，以及实际拼接 addon 的原生配置关闭恢复。可用 `HD2_MOD_OPTIONS_MENU_SOURCE` 指定菜单 Lua 源码；第三方源码不随本仓库分发。
