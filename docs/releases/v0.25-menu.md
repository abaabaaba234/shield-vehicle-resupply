## v0.25-menu：游戏内参数调节与中英切换

基于 v0.25，新增 **27 项 MODS 菜单控件**。保留护盾内载具回血、补弹、部位维修、武器／大盾／轮胎故障保护，以及修满机甲后的移速、腿部火焰和跛行动画恢复。

### 安装与使用

1. 安装 Bingus Shared Loader v17+（可使用 v18）。
2. 另行安装提供 **ModOptionsMenu API 1 / version 2** 的参数菜单模组。加载器和参数菜单是两个独立模组。
3. 用 mod 管理器导入本页附件 `ShieldVehicleResupply_v0.25-menu.zip`，替换旧版 Shield Vehicle Resupply，部署后重启游戏。
4. 打开 **Esc → MODS → 护盾载具回血补弹**，调整参数并点击“应用”。

对应 Helldivers 2 Steam build **25480438**，沿用 v0.25 的游戏代码与布局校验。

| 开关 | 默认 | 作用 |

| 启用模组 | 开 | 总开关；关闭时停止维修、补弹与保护，并走原有恢复流程 |
| 补充弹药 | 开 | 给关联的机甲、坦克武器补弹；FRV 不补弹 |
| 部位再生默认开关 | 开 | 部位再生默认策略，文件里的 `part=` 独立覆盖仍有效 |

| 机甲武器故障保护 | 开 | 非盾牌武器到 1 HP 时暂存弹药，修复严格超过 5% 后归还 |
| EXO-55 盾臂保护 | 开 | 盾臂／盾面触底时禁用盾击，各故障区域超过 5% 后恢复 |
| FRV 轮胎故障保护 | 开 | 保留轮胎模型，触底施加原生爆胎状态，超过 5% 后恢复 |

| 仅本机有权威时写入 | 开 | 沿用本机权威限制 |

| 忽略护盾（测试模式） | 关 | 所有载具均可回复，用于单人私人任务测试 |
| 记录附近实体（诊断） | 关 | 记录新出现的附近实体，增加诊断处理量 |

### 选项与配置保存

- **Language**：简体汉字／English，默认中文。只影响本模组。应用后关闭并重新打开 Esc 菜单刷新标题、标签和说明；English 在菜单样式中显示为 ENGLISH。
- **回血方式**：游戏原生／旧版数值回填／关闭回血，默认游戏原生。对应 `heal=native|write|off`；补弹和保护由各自开关控制。
- 应用后保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\shield_resupply_settings.txt`，重启后保留。菜单显示百分比，文件仍保存原比例，例如 4% 为 `exo_heal=0.04`。
- 保存仅更新改动字段，保留旧配置、注释、自定义护盾／武器 hash、弹药上限及独立部位策略。语言修改只保存语言；业务修改复用原有配置、弹药和轮胎恢复路径。
- `part=`、`shield=`、`weapon=`、`ammo_max=`、`native_zone`、`native_segments`、`native_force` 继续通过设置文件调整，手改后发送 `reload`。
- 菜单范围仅限制菜单操作；文件中的超范围或非步长数值仍保留，直到用户应用该行的新选择。
- 没装菜单或菜单接口不可用时，原有设置文件和命令继续可用。
