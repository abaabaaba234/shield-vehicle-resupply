# Shield Vehicle Resupply v0.25-menu-perf3

护盾载具回血补弹性能优化版。保留 v0.25-menu 的中英 MODS 参数菜单、回血补弹、部位维修及武器／盾臂／轮胎保护规则。

## 更新

- 缓存已验证的静态接口、配置槽位与未变化的实体索引，避免重复扫描和解析。
- 健康手臂／轮胎改为轻量巡检，仍约每 50 毫秒读取新鲜血量与身份，达到 1 HP 当轮进入完整故障处理。
- 完整配置与轮胎物理参数每秒核对；故障轮胎继续高频查询，不反复读取其余完好轮胎。
- 合并移速、火焰与跛行动画的基础采样；三项正常后降低重复检查频率。
- 合并零碎读取、复用 FFI 缓冲区、清理消失实体与临时引用，减少临时分配和长期状态保留。
- 恢复失败保留原值，每 0.5 秒重试；已完成的恢复不反复读取。

## 验证

- 15 个离线回归脚本全部通过，涵盖身份／权限变化、故障锁存、恢复重试、配置缓存失效和 ZIP 载荷一致性。
- 同一模拟样本每秒 20 次巡检：健康单手臂读取 2960 → 869 次，健康 FRV 2720 → 703 次；单轮故障参数读取 80 → 23 次。仅为模拟计数，不代表实际 CPU 或帧率提升百分比。
- 2026-10-04 用户完成游戏内测试，确认当前性能可接受；尚无本版精确分项耗时与长期内存曲线。
- 保留约 50 毫秒故障检测、1 HP 锁存及严格超过 5% 才恢复的规则，写前身份核对与写后读回仍保留。
